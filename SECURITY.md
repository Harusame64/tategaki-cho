# Security policy

## Supported versions

Only the latest release of たてがき帖 receives fixes.

## Reporting a vulnerability

Please do not report security problems in a public issue. Use GitHub's private vulnerability
reporting instead: open the **Security** tab of this repository and choose **Report a
vulnerability**.

Useful to include:

- what the problem is and what it lets someone do;
- how to reproduce it (the app version, the Android version, and the steps);
- a fix, if you have one in mind.

Reports are read as soon as possible, usually within a week. A confirmed problem is fixed in a new
release, and the report is credited unless you ask otherwise.
