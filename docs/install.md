# たてがき帖をインストールする

Google Play で公開される前の試用版を、Android のスマホにインストールする手順です。Android 13 以上で使えます。

インストールには、アプリを配布するための「APK ファイル」を使います。

## インストールする

1. スマホで[ダウンロードページ（Releases）](https://github.com/Harusame64/tategaki-cho/releases)を開きます。いちばん上にあるバージョンの `tategaki-cho-<版>.apk` をタップして、ダウンロードします。`<版>` の部分には、バージョン番号が入っています。

2. ダウンロードした APK ファイルを開きます。「この提供元のアプリはインストールできません」と表示された場合は、次の操作をしてください。
   - **設定**を開きます。
   - APK ファイルを開いたアプリ（Chrome など）の設定で、**この提供元のアプリを許可**をオンにします。
   - 元の画面に戻り、APK ファイルをもう一度開きます。

3. **インストール**をタップします。Play プロテクトが「不明なアプリ」と警告することがあります。その場合は、画面の案内に沿ってインストールを続けてください（**詳細**を開くと、続けるためのボタンが出ることがあります）。

インストールが終わったら、手順 2 でオンにした**この提供元のアプリを許可**は、オフに戻してかまいません。

## アプリを更新する

新しいバージョンの APK ファイルを同じ手順でインストールすると、アプリが更新されます。本棚や読んでいた位置は、そのまま残ります。

**更新するときは、アプリをアンインストールしないでください。** アンインストールすると、保存した本文も本棚も消えます。

## アンインストールする

次のどちらかの方法で、アプリをアンインストールできます。

- ホーム画面またはアプリの一覧で、たてがき帖のアイコンを長押しします。**アンインストール**が表示されたらタップし、画面の案内に従います。
- **設定**で**アプリ**を開き、アプリの一覧から**たてがき帖**を選びます。**アンインストール**をタップし、画面の案内に従います。

アンインストールすると、本棚に入れた作品と読んだ位置、保存した本文、読書の記録、表示の設定がすべて消えます。

## ダウンロードしたファイルを確認したいとき（詳しい方向け）

各バージョンのダウンロードページに、APK ファイルの SHA-256 を載せています。ダウンロードしたファイルから計算した値が同じなら、掲載されたものと同じファイルだと確かめられます。
