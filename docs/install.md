# たてがき帖を APK で入れる

Google Play に出る前の試用版を、APK ファイルから入れる手順です。Android 13 以上で動きます。

## 入れる

1. スマホで [Releases](https://github.com/Harusame64/tategaki-cho/releases) を開き、いちばん上の版の
   `tategaki-cho-<版>.apk` をタップして保存します。
2. ダウンロードした APK を開きます。「この提供元のアプリはインストールできません」と出たら、
   **設定** を開いて、いま使っているアプリ（Chrome など）の **この提供元のアプリを許可** をオンにし、
   戻ってもう一度開きます。
3. **インストール** を押します。Play プロテクトが「不明なアプリ」と警告することがあります。
   **詳細** → **インストールする** で進めます。

入れ終わったら、2 で許可した設定はオフに戻してかまいません。

## 新しい版にする

新しい版の APK を同じ手順で入れると、上書きされます。本棚や読んだ位置はそのまま残ります。
**アンインストールはしないでください。** アンインストールすると、保存した本文も本棚も消えます。

## 確かめたいとき

各版のページに APK の SHA-256 を載せています。ダウンロードしたファイルの値と同じなら、
途中で書き換えられていません。
